# Vault Dashboard

[English](README.md) | 简体中文

为 [Obsidian](https://obsidian.md) 提供仓库存储全景看板：体积构成、文件分布与健康度一览，帮助你快速发现大文件与无引用附件。

![Obsidian Downloads](https://img.shields.io/badge/dynamic/json?logo=obsidian&color=%23483699&label=downloads&query=%24%5B%22vault-dashboard%22%5D.downloads&url=https%3A%2F%2Fraw.githubusercontent.com%2Fobsidianmd%2Fobsidian-releases%2Fmaster%2Fcommunity-plugin-stats.json)

## 功能特性

### 存储概览

- **Hero 核心指标** — 已索引总占用、文件数、目录数三项大指标，附带分类占比进度条。
- **分类统计** — 将文件分为 Markdown、图片、附件与其他，展示各类体积与占比条。
- **磁盘估算（桌面）** — 可选递归扫描文件夹总占用，包含 Obsidian 未索引的文件（如 `.obsidian/` 配置目录）。

### 空间占用分析

- **Squarified 树图** — 以层级树图展示仓库空间，矩形面积代表文件/文件夹大小。
- **钻取导航** — 点击文件夹下钻；顶部面包屑可跳回任意祖先层级。
- **智能聚合** — 单层子节点超过 80 个时，小项合并为「其他 N 项」，避免 DOM 爆炸。
- **多种图表** — 可在树图、旭日图、环形图、条形图之间切换。
- **类型筛选** — 按全部 / Markdown / 图片 / 附件 / 其他筛选，聚焦特定内容。

### 洞察面板

- **增长趋势** — 过去 12 个月当前文件累计体积走势及变化量。
- **活跃度热力图** — 近 13 周编辑频次，以及今日/本周编辑与新建统计。
- **最近活动** — 最近修改与新建的笔记一览。
- **仓库健康度** — 侧栏健康摘要，必要时提示断链等情况。

### 体积最大的文件

- 可配置显示数量（**10 / 20 / 50**），支持按大小或修改时间排序、分类筛选与搜索。
- 行内操作：**在 Obsidian 中打开**、**复制仓库相对路径**、**在系统文件管理器中显示**（仅桌面）。

### 孤儿附件扫描

- 基于 Obsidian `resolvedLinks` 元数据，找出未被任何笔记引用的文件。
- **深度扫描**（可选）— 额外解析各笔记元数据中的链接、嵌入与 frontmatter 链接，减少误报。
- **正文兜底扫描**（可选）— 用正则读取 Markdown 正文，捕获元数据未覆盖的内联链接。性能开销大，仅在仍有疑虑时开启。
- 实时进度与取消支持。
- 每条孤儿结果支持：复制路径、在管理器中显示、在 Obsidian 中打开。

### 库身份名片

- 固定在右侧边栏底部的库标识名片，显示库名与可选自定义文字。
- 动态跟随右侧边栏宽度，位于状态栏上方。
- 可配置：显示开关、自定义名称、主题色、透明度。
- 命令面板：**切换库身份名片显示**。

### 通用

- **双语界面** — 随 Obsidian 语言设置自动切换中文 / English（`getLanguage()` API，需 Obsidian ≥ 1.8.7）。
- **会话缓存** — 扫描结果在会话内缓存于内存；点击 **Refresh** 重新扫描。
- **明暗主题** — 样式使用 Obsidian CSS 变量（`--color-accent`、`--text-normal` 等）自适应主题。
- **移动端兼容** — 桌面与移动端均可用（`isDesktopOnly: false`）。磁盘估算、管理器显示等桌面专属功能在移动端自动隐藏。

## 安装

### 从社区插件安装（推荐）

1. 打开 **设置 → 社区插件 → 浏览**。
2. 搜索 **Vault Dashboard**。
3. 点击 **安装**，然后 **启用**。

### 手动安装

1. 从 [最新 Release](https://github.com/Lemon695/obsidian-vault-dashboard/releases) 下载 `main.js`、`manifest.json`、`styles.css`。
2. 创建目录：`<你的库>/.obsidian/plugins/vault-dashboard/`
3. 将三个文件放入该目录。
4. 重载 Obsidian，在 **设置 → 社区插件** 中启用 **Vault Dashboard**。

## 用法

- 点击左侧 Ribbon 的 **饼图图标**，或在命令面板运行 **打开信息面板**。
- 新 Tab 中打开完整仪表盘视图。
- 点击顶栏 **Refresh** 重新扫描仓库。
- 在侧栏点击 **Scan Orphans** 扫描无引用附件。
- 在空间占用图表中点击文件夹下钻；用面包屑返回上层。
- 在分析面板顶栏切换图表模式与类型筛选。

## 设置

### Dashboard

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 忽略路径前缀 | 统计已索引文件时跳过这些相对路径，**每行一条**（如 `large-videos`） | （空） |
| 显示磁盘目录总占用（桌面） | 启用递归文件夹体积估算 | 关 |
| 扫描让出频率 | 每处理 N 个已索引文件后让出主线程（0–100；0 = 关闭） | 25 |
| 孤儿扫描：深度解析 Markdown 元数据 | 解析元数据链接/嵌入以提高孤儿检测准确度 | 开 |
| 孤儿扫描：终极兜底正文扫描 | 用正则扫描笔记正文中的链接 | 关 |

### 库身份名片

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 显示库标识名片 | 在右侧边栏显示身份名片 | 开 |
| 自定义库名称 | 名片上的附加文字；留空则使用库文件夹名 | （空） |
| 名片主题色 | 名片边框强调色 | 主题默认 |
| 名片透明度 | 名片透明度（0.1–1.0） | 0.8 |

## 开发

```bash
npm install
npm run dev      # 监听构建
npm run build    # 类型检查 + 生产构建
npm run lint     # ESLint
```

构建产物为项目根目录的 `main.js`（不是 `dist/`）。

### 手动测试

将 `main.js`、`manifest.json`、`styles.css` 复制到：

```
<库路径>/.obsidian/plugins/vault-dashboard/
```

重载 Obsidian 并启用插件。
